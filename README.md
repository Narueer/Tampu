# TAMPU – Estudia tranquilo

Plataforma web de vivienda y trabajo verificados para estudiantes que llegan de provincia a Cusco.
Proyecto del curso Programación Web – Universidad Continental (NRC 39578).

Página en vivo: https://narueer.github.io/Tampu/

## Cómo verlo
Abrir el enlace de arriba, o descargar el repositorio (Code → Download ZIP) y abrir `index.html` en el navegador.

## Páginas
- index.html – inicio
- habitaciones.html – lista de habitaciones con filtros
- habitacion.html – detalle de una habitación
- trabajos.html – ofertas de trabajo
- login.html / registro.html – iniciar sesión y crear cuenta
- nosotros.html – sobre el proyecto

## Tecnologías
HTML5, CSS3 (Flexbox y Grid) y JavaScript. Más adelante: Laravel y MySQL.
